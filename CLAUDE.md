# yulia.profinance

Монорепозиторій: `apps/landing` (/), `apps/planner` (/planner/), `packages/design-system`. Команди в [README.md](README.md).

## Спілкування
Користувач не технічний: українською, просто, без жаргону, звертання на «ви». Технічне вирішуй сам, питай про продукт.

## Журнал рішень
- На старті розмови читай [docs/decisions.md](docs/decisions.md).
- Важливе рішення (продукт, вигляд, адреси, стек, що НЕ робимо) → один рядок зверху + скажи користувачу одним рядком. Дрібниці не пиши.
- Відкрите питання вирішено → прибери його звідти.

## Тримай файли короткими
Цей файл ≤ 40 рядків, журнал ≤ 60. Коли ростуть: стискай формулювання, об'єднуй, закреслені рішення старші за 3 місяці видаляй.

## Правила розробки
- Новий застосунок: `apps/<назва>/` + рядок у `scripts/build.sh` (+ `workspaces`, якщо є збірка). Застосунки не імпортують один одного; спільне → `packages/`.
- Кольори й шрифти беремо з `packages/design-system`; змінюєш токен, змінюй в усіх застосунках.
- Перед пушем: `nvm use && npm run build` без помилок; перевір вигляд на 360 px і десктопі. Один коміт = одна зміна.
- TypeScript `strict`. Фінансові розрахунки: чисті функції в `src/lib/` з тестами Vitest. Валюту завжди підписуй.
- Нові залежності лише за потреби.
- Фінансові дані користувачів лишаються в браузері, якщо в журналі не вирішено інакше. Жодних ключів і даних клієнтів у репозиторії.
