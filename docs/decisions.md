# Журнал рішень

Один рядок на рішення, найновіші зверху. Змінене рішення не видаляємо, а закреслюємо (~~так~~) і додаємо нове.

- 2026-10-21 · Ціни ETF для ребалансу щодня підтягуються з justETF (неофіційне джерело; збирається разом із сайтом о 07:00); якщо ціни немає або потрібна своя — вписується вручну.
- 2026-10-15 · Валюта плану — лише $ або €. Доходи й витрати можна вписувати в ₴: вони перераховуються за курсом НБУ (або ручним). Нові плани за замовчуванням у ₴.
- 2026-10-15 · Курси $ і € беремо автоматично з відкритого API НБУ; якщо курс вписано вручну — план використовує його. Решту ринкових даних щомісяця оновлює Claude у хмарі й одразу публікує.
- 2026-10-15 · Сторінка «Припущення»: цифри плану (інфляція, дохідність, ріст доходу, курси) в одному місці + ринкові дані з датою й джерелами (`data/assumptions.ts`); оновлюються на прохання «онови припущення», після 90 днів — попередження.
- 2026-10-15 · Перенесено решту вкладок прототипу: «Активи» (розподіл коштів), «Портфель» (ETF + ребаланс), «План дій» (ROADMAP + корисні посилання), готівка за валютами й драбина облігацій. Реферальні посилання, промокоди й контакти не переносимо.
- 2026-10-15 · Працюємо локально (localhost:5173), на GitHub пушимо після більшого шматка.
- 2026-10-15 · Крок «Захист»: довідник страхових програм із таблиці Юлії (вкладки UPD), обрані програми йдуть у план і PDF. Знижки партнерів не показуємо; програми, що не продаються або лише за кордоном, прибираємо. Оновлення — Юлія змінює таблицю, Claude переносить і перекладає українською.
- 2026-10-15 · Планер v1 = 4 кроки з таблиці Юлії: доходи/витрати → резервний фонд → цілі → фінансова свобода + підсумок у PDF.
- 2026-10-15 · Планером користується Юлія разом із клієнтом; кілька клієнтів, дані лише в браузері, підсумок зберігається в PDF.
